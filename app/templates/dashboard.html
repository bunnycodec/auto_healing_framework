AI Auto-Healing Framework Python · FastAPI

Detect broken Playwright locators, fix them with AI, validate, and report.

API

MethodEndpointPurpose
POST/runHeal a single trace.zip
POST/heal-directoryHeal a results folder (with locator dedup)
POST/orchestrateRun tests, collect traces, then heal
GET/reportsList generated JSON healing reports
GET/healthService health check

Example

curl -X POST http://localhost:8000/run \
  -H "Content-Type: application/json" \
  -d '{"trace_zip": "path/to/trace.zip"}'

Configure the AI provider with AI_MODE (rule, azure-openai, ollama, kilo) in your .env.
